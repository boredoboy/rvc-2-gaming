# RVC Realtime для Kaggle

Браузерный realtime RVC-клиент, который использует Kaggle GPU для преобразования голоса. На домашнем ПК остаются захват микрофона и воспроизведение; аудиоблоки идут по защищённому WebSocket к Kaggle. В интерфейсе можно загрузить собственную RVC-модель `.pth` и соответствующий `.index`.

Проект использует [OpenVoiceChanger](https://github.com/sioaeko/OpenVoiceChanger) как realtime WebSocket интерфейс и RVC backend. Исходники upstream скачиваются на Kaggle по зафиксированным Git commit SHA; код приложения и ассеты не копируются в этот репозиторий.

## Что важно знать

- Kaggle `Save & Run All` создаёт отдельную вычислительную сессию. Пока notebook выполняется, сервер доступен, даже если закрыть вкладку на ПК. Это временная сессия, не постоянный хостинг; Kaggle ограничивает длительность notebook-запуска.
- Включите Internet и GPU T4 в настройках Kaggle Notebook. При первом старте скрипт установит Python 3.10, RVC зависимости, веб-интерфейс и проверенные HuBERT/RMVPE веса. Подготовка занимает время и каждый новый Kaggle runtime повторяет установку.
- Загруженные модели хранятся в `/kaggle/working` и исчезают вместе с Kaggle runtime. Перед следующей сессией загрузите модель заново.
- Публичный адрес Cloudflare временный и меняется при каждом запуске. Ссылка сама по себе не требует Cloudflare-аккаунта; RVC интерфейс защищён паролем из Kaggle Secrets.
- Реальная задержка зависит от сети, выбранного F0 метода, размера аудиоблока и GPU. Для игр с быстрым разговором задержка через Kaggle может оказаться заметной.
- Загружайте только корректные RVC v1/v2 чекпойнты и используйте голоса/модели, на применение которых у вас есть права. Любые `.pth` файлы не обязательно являются RVC моделью.

## Подготовка Telegram

Токен, присланный в чате, уже раскрыт. **Отзовите его в BotFather и создайте новый**, затем добавьте новый токен только как Kaggle Secret. Не вставляйте его в notebook, GitHub, `.env` или вывод ячейки.

Создайте в Kaggle Notebook secrets с такими именами:

| Secret | Значение |
| --- | --- |
| `RVC_ACCESS_PASSWORD` | Случайный пароль минимум из 20 символов. Вводится на странице входа. |
| `RVC_TELEGRAM_BOT_TOKEN` | Новый токен бота из BotFather. |
| `RVC_TELEGRAM_CHAT_ID` | Ваш числовой Telegram ID, его можно узнать у `@userinfobot`. |

Разрешите этим secrets доступ текущему Kaggle Notebook в меню **Add-ons → Secrets**. Перед запуском откройте чат своего бота и нажмите **Start** — иначе Telegram не даст боту написать вам ссылку.

## Запуск в Kaggle

1. Откройте `kaggle_rvc.ipynb` в репозитории, скачайте его и импортируйте как Kaggle Notebook.
2. В настройках notebook включите **Internet** и **GPU T4**.
3. Добавьте три Kaggle Secrets из таблицы выше.
4. Нажмите **Save Version → Save & Run All**. Скрипт соберёт backend, создаст временный туннель и отправит ссылку Telegram-ботом.
5. Откройте ссылку в Chrome или Edge, введите `RVC_ACCESS_PASSWORD`, загрузите `.pth` и, если есть, `.index`, активируйте модель.
6. На вкладке Studio выберите Input — микрофон; Output — **CABLE Input (VB-Audio Virtual Cable)**; F0 — например `pm` или доступный `rmvpe`/`fcpe`; нажмите **Start Voice Changer**.
7. В Discord выберите **CABLE Output (VB-Audio Virtual Cable)** как устройство ввода. Для Telegram Desktop используйте тот же микрофонный вход при звонках и записи голосовых. На Windows нужно установить VB-CABLE заранее.
8. Когда закончите, отправьте боту `/stop`. Он закроет туннель и сервер, затем notebook завершит работу. Также можно остановить Kaggle-сессию вручную.

Команды бота: `/link`, `/status`, `/stop`.

## Безопасность

- Этот репозиторий содержит только код. Не добавляйте сюда Kaggle Secrets, Telegram токен, голосовые модели, записи или `.index`.
- Приложение слушает только `127.0.0.1`; наружу направлен лишь Cloudflare Quick Tunnel. Вход закрыт паролем, а Telegram команды принимает только от настроенного `RVC_TELEGRAM_CHAT_ID`.
- Quick Tunnel предназначен для временного тестирования: адрес перестаёт работать после остановки `cloudflared`. Не пересылайте ссылку и пароль посторонним.
- Код туннеля загружает пакет из официального Cloudflare APT-репозитория, а Node.js скачивается с официального сайта и проверяется по SHA-256. HuBERT/RMVPE веса также сверяются с зафиксированными SHA-256.

## Локальная структура

- `kaggle_rvc.ipynb` — Kaggle notebook для запуска.
- `scripts/run_kaggle.py` — установка зависимостей, загрузка весов, запуск сервера, туннеля и Telegram управления.
- `scripts/serve.py` — локальный ASGI старт приложения с парольным шлюзом.
- `scripts/security_gate.py` — вход по паролю для HTTP API и WebSocket.
